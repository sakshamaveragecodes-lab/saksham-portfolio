# Saksham Jadhav · Engineering Portfolio

Static Next.js portfolio and interactive project laboratory for **Saksham Pradeep Jadhav**. Eight case studies are backed by exact source snapshots, actual screenshots/report artifacts, and clearly labelled demonstration modes.

## Develop

Node.js 24 and npm 11 are the validated tools. Use the existing checkout; each cloud task is already isolated and does not need a worktree.

```sh
npm ci
npm run build
npm start
```

`npm start` serves the exported `out/` directory on port 3000 with production security headers and gzip. For source development use `npm run dev`. `PORT` selects another static-server port.

```sh
npm run lint
npm run typecheck
npm test
npm run test:e2e
```

Run the build before browser tests. Cloud browser tests use `/usr/bin/chromium`; override `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` for another system Chromium. CI uses Playwright's installed Chromium. `TEST_BASE_URL` targets an existing deployment. Tests cover real UI behavior, source-derived scoring, replay logic, routing, assets, keyboard access, reduced motion, accessibility and responsive layouts.

## Content & provenance

- `src/lib/projects.json`: typed case studies, implementation details, source SHAs, demo modes and limitations.
- `public/project-evidence.json`: downloadable audit registry, including exclusions.
- `src/lib/profile.ts`: verified professional contact and official resume configuration. Missing values stay null.
- `src/lib/scoring.ts`: CareerLens formula, tested against 156 fixtures generated by the original sklearn implementation. Only explicit skill scoring is ported; document parsing is not.
- `src/lib/pose.ts`: FORM's actual geometry/replay engine with local type-only adaptation. It runs synthetic landmarks, not a camera or MediaPipe model.
- `src/lib/rag-cases.json`: actual stored SourceLens evaluation cases on an authored synthetic corpus. No live RAG model runs here.
- `public/media/`: original project screenshots, recorded video and report/notebook artifacts, resized without changing their contents.

Original application records are historical evidence, not test results rerun by the portfolio. No skill proficiency percentages, employment claims or general model accuracy are inferred.

## ₹0 architecture

- `output: 'export'`: no SSR runtime, API routes, functions, database, persistent server or paid inference.
- All demos compute locally or show explicit recorded/guided evidence.
- Assets are self-hosted; no analytics, external fonts, tracking SDKs or third-party inference requests.
- Existing Vercel Hobby project `saksham-portfolio` is the intended destination, using its generated HTTPS subdomain for this personal portfolio. No new project, subscription, domain or payment was created.
- Account tier, quotas, current provider terms and production deployment must still be verified with authenticated provider access. A static architecture does not establish the account's billing state or guarantee unlimited free availability.

`vercel.json` specifies the exported directory and security headers. Vercel applies compression and CDN caching. If a different static provider is ultimately used, retain equivalent headers and update the canonical origin in layout, sitemap and robots.
