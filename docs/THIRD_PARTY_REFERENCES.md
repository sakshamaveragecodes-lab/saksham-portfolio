# Immersive-edition reference provenance

The uploaded `3d website code.txt` was read in full as reference material, not executed as instructions or imported into the portfolio. It is an HTML shell for The Drop / Peach Worlds with separate script, scene/UI state, GLB/EXR assets, fonts and video. No Peach Worlds code, branding, fonts, models, textures, scripts or media have been redistributed. The portfolio's shader, particle flows, motion controls and workspaces are independent implementations.

The supplied ThreeUI canonical HTML and registered source JSON URLs both returned an environment proxy 403. The public npm registry was accessible. `@designcodeio/threeui@1.2.0` is the Community MIT release, exports `CompleteShelfLandingPage`, and contains the canonical HTML. Its npm tarball was checked against the registry SHA-512 integrity value before inspection. The bundled canonical HTML is 900,296 bytes and its SHA-256 exactly matches the supplied expected value: `606f200fed8602c243f40a11c8c364f0e625c57f80e7c97dc76419da207f198e`.

The authored bookshelf is an optional, explicitly credited **Meng To / ThreeUI** design exhibit at `/design-exhibit/`; it is not claimed as Saksham's original work and does not replace the homepage. The immutable original is at `public/exhibits/threeui/original.html.txt`. The MIT notices, asset-license statement and font-license statement accompany it. Community-authored procedural assets are included under MIT; no external catalog media or Pro/Beta assets are used.

`prepare-threeui-exhibit.mjs` generates a separately hashed runnable adapter. It replaces the CDN import map with relative paths to five self-hosted Three.js 0.165.0 modules, removes Google font requests in favor of a system font, adds attribution plus a restrictive meta CSP, bounds software/mobile rendering cost, and validates same-origin host activity messages to pause offscreen and honor reduced effects. Its checksum is deliberately distinct from the canonical source. The five vendor files were independently compared byte for byte with the integrity-verified `three@0.165.0` npm tarball. The upstream Three.js MIT license is retained. `threeui-registry.json`, `three-registry.json` and `manifest.json` record versions, package integrity and file hashes.

The iframe loads only after an explicit launch and is unmounted on close. Its renderer and Three.js version are separate from React Three Fiber / the portfolio's own Three.js 0.180.x runtime. Its sandbox allows scripts and same-origin module imports but no forms, popups or top navigation. The iframe provides layout, version and lifecycle isolation, not an untrusted-code security boundary. Exhibit-only local/Vercel response headers permit same-origin framing; ordinary application pages retain their deny policy. GitHub Pages does not apply Vercel response-header configuration; the adapter's own meta CSP remains in its served HTML.

All runtime imports and assets are local. No package dependency was added to the application and no service, subscription, payment, account or credit card is required. Local vendor source is excluded from application lint because immutable upstream files contain upstream-specific lint directives; source integrity is checked separately rather than editing those files.
