## Rendering and resource contract

`production/renderer.tsx` coordinates one persistent Three.js WebGL2 stage for all ordinary cinematic routes. Where OffscreenCanvas transfer is supported, the same `production/engine.ts` runs in a dedicated worker; unsupported browsers dynamically load the identical engine on the main thread. A short-lived capability probe is released before the persistent context starts. No simultaneous duplicate scene renderer is created. It retains the canvas across App Router navigation, interpolates the camera from its preceding pose, removes and disposes the preceding scene's geometry/materials (including asynchronous stale GLBs), and builds only the new environment. `Model.batch()` combines immutable geometry by material. Morph topology remains constant; the same meshes unfold rather than being swapped for color variants.

An original angular softbox cube environment supplies controlled metal highlights. Each environment has an authored key/rim arrangement, reflection-rig yaw, material roughness and exposure; FORM uses lateral satin lighting, StudyBuddy a warm reading-room arrangement, the passage deep backlighting, and the city broad overhead light. Off-axis projection leaves space for typography while the camera continues to aim through the actual architecture. The SourceLens liquid is above the imported process bed, rather than concealed underneath it. Mobile/software rendering uses refracted environment lighting. Capable desktop uses one reduced-size screen-background pass for thin-volume glass and a planar reflection. Shadow maps are limited to desktop hardware. `?optics=full` is an explicit inspection diagnostic which forces that expensive path, including software; its results must not be confused with the adaptive default. Nested reflection draws restore glass visibility using a local visibility stack.

The liquid is an interactive, bounded linear shallow-water height field with advected curl detail. It is not a volumetric CFD simulation. Glass is a thin-volume approximation, not ray-traced multi-bounce optics or caustics. Silver surfaces use a custom environment/Fresnel material, not a promise of offline path-traced rendering.

Adaptive device pixel ratio uses observed frame intervals. Software desktop starts at0.6 and may reduce to0.55; mobile starts at0.7 and may reduce to0.55. Hardware desktop caps at1.4; mobile caps at1.1. This intentionally limits software fill cost; physical GPU measurements are still required to establish hardware frame rate and sharpness. A breakpoint rebuild releases old geometry without creating a second context. Native modal, specialist walkthrough and hidden-document states suspend ordinary scene rendering. Reading backgrounds render on demand when their scroll, pointer, selection or section pose changes; they stop submitting GPU frames when settled. Software and low-memory devices use the compact geometry tier without changing desktop typography or camera composition. The source archive uses two instanced draw calls for its eighteen retained leaves; the39 CareerLens terrace markers use one instanced draw. Software rendering uses CPU vertex blending equivalent to the GPU absolute morph-target formula, preserving the earlier Foundry optimization. Physical GPUs retain GPU morphing. Pause freezes material time while deliberate scrolling remains possible. Resize happens before drawing, avoiding buffer-clear flashes.

Missing WebGL2/float render-target support, shader/asset initialization failure or context loss exposes the complete semantic reading edition and existing tools. Reduced motion creates no ordinary renderer. Every original preview, full application workspace, demonstration, technical diagram, provenance record, resume download and credited ThreeUI exhibit remains available. No backend, inference API, remote asset dependency, subscription or paid infrastructure was added.

## Reproducible browser checks

The browser suite uses one worker because cloud/CI scenes share a software GPU. Two simultaneous GPU-heavy browsers caused the180-second aggregate history journey to time out even when that identical16-route test passed alone in120seconds. Timeouts, assertions and the zero-retry policy are unchanged. The suite still exercises every route, both device widths, keyboard/reduced motion, preserved tools, real resource disposal and rendering failures. GPU/frame-rate measurements and recordings run separately from the suite. This is resource scheduling, not a claim of hardware smoothness.

Separation controls remain effective after the automatic scroll-driven opening: the folio exposes its local enclosure, About strata physically spread, Skills bridges expose their core, and Contact ducts separate. A geometry-state invariant tests all14 controls at the late chapter and reverses them to the identical pose.

## Startup and loading

Original angular softbox and curl maps are losslessly baked by `node --import tsx scripts/bake-studio-textures.ts`, using the same original material/flow functions through a minimal build-only canvas adapter. SHA manifests and a pixel-equivalence test verify every decoded RGBA byte. Seven PNGs total104627bytes; they are served locally with the GitHub Pages base path. A missing map exposes the complete readable edition rather than a blank stage. No third-party runtime image service is involved.

Geometry construction yields between modeled operations within a6ms budget, retaining identical geometry/choreography. Stale construction is cancelled and disposed. The canvas is present in the initial HTML and remains React-owned across renderer lifecycle changes; its CSS viewport size does not change when pixel resolution adapts. Reduced motion removes the renderer and preserves readable sections. GLB parsing code is lazy-loaded only for SourceLens. Whole-scene/budgeted parallel compilation and early preload experiments did not improve the measured software loading cost and were excluded. None of these loading changes simplifies the actual authored environments.

## Worker isolation

The worker receives only numeric/boolean scene state, viewport dimensions and project selection. Camera progress comes back from the rendered timeline to drive the existing semantic chapter text. No DOM is moved into a worker, and no application inputs or professional documents are transmitted to a service. Studio images decode through ImageBitmap in the worker, with the same color-space/filtering settings; disposal closes their bitmaps. The original GLB is loaded only for SourceLens.

ResizeObserver caches the viewport; the bridge avoids a forced layout read on every animation frame and posts changed state only. It schedules startup after the React effect task so StrictMode's initial cleanup cannot transfer the same canvas twice. Cleanup disposes the engine/context, acknowledges worker shutdown and terminates a stalled worker after500ms. Context loss/missing maps/unsupported float targets preserve the complete reading edition. Main-thread heap samples exclude worker memory and VRAM; worker isolation is not a claim of lower total memory or faster physical GPU rendering.
