Evidence Foundry / original Project Saksham asset

chamber.glb and chamber-compact.glb are generated by scripts/build-foundry-assets.py using Blender4.3.2.
It contains original modeled geometry and materials only, no external image,
texture, font, video, paid asset or MORPHO artwork. Six iris leaves remain separate;
immutable architecture is batched by material. It has no external resource URIs.

Regenerate from repository root:
blender -b --python scripts/build-foundry-assets.py -- /absolute/path/chamber.glb
blender -b --python scripts/build-foundry-assets.py -- /absolute/path/chamber-compact.glb --lod

The application uses the existing MIT-licensed Three.js dependency and its
Reflector helper. Source leaves, coordinates and fluid surfaces are conceptual
artwork, not real documents, AI results or model evaluations.
